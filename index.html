BRACU Connect Utility

BRACU Student Connect Helper

Search course sections and check live seat status using the BRACU Connect session already signed in to the browser.

Install

Copy the launcher, save it as a browser bookmark, then run it while signed in to BRACU Connect.

Open BRACU Connect

  1. Create a new browser bookmark.
  2. Name it BRACU Connect Helper.
  3. Paste the copied launcher into the bookmark URL field.
  4. Sign in to BRACU Connect normally.
  5. While on BRACU Connect, click the saved bookmark.

What it shows

Course details Course, section, faculty, day, time, room and credit.
Seat status Total seat, booked seat, remaining seat and availability.
Search Filter by course code, faculty, section, day or room.
Live refresh Refresh BRACU data from the current signed-in session.

Session handling

The launcher runs inside connect.bracu.ac.bd. BRACU login data stays in the BRACU browser session and is not sent to this GitHub Pages site.

Independent helper project. Not an official BRAC University application.
